# 真实硬件替换与验收清单

首版工程“面向常见 Blue Pill 可构建、可生成烧录镜像”，不等于“未知实物接上必然运动”。在给电机上电前逐项确认。

## MCU 与时钟

- [ ] 实际丝印是 STM32F103C8T6、CBT6，还是其他型号/兼容芯片；Flash/RAM 容量是否匹配 PlatformIO board。
- [ ] 外部晶振实际为 8 MHz 且能稳定起振；若没有 HSE，应修改 `board_system_clock_config()` 和时钟宏。
- [ ] BOOT0 下拉、BOOT1 状态正确；ST-Link 的 SWDIO、SWCLK、GND、3V3 连接可靠。
- [ ] 下载器给板供电还是目标板独立供电，避免两个 3.3 V 电源互相顶。

## UART 与 RK3576

- [ ] RK3576 UART 是 3.3 V TTL，不是 1.8 V、5 V 或 RS-232；不一致时加电平转换。
- [ ] STM32 PA9(TX) 接 RK RX，PA10(RX) 接 RK TX，双方 GND 共地。
- [ ] RK 串口未被系统 console/getty 占用，设备节点权限正确，确认为 115200 8N1、无流控。
- [ ] 先做 USB-TTL/逻辑分析仪回环，核对 CRC 和小端 float，再接主控。

## 电机驱动

- [ ] 驱动器到底是 TB6612、L298、BTS7960 还是集成板；确认它是否接受“单 PWM + IN1/IN2”真值表。
- [ ] 若驱动是双 PWM（LPWM/RPWM）或 DIR+PWM，必须改 `board_motor_set_percent()`，不可直接照接。
- [ ] TB6612 的 STBY、其他驱动的 EN/FAULT 脚已按手册处理；当前默认没有单独控制 STBY。
- [ ] MCU 3.3 V 高电平满足驱动输入阈值；电机电源与逻辑电源去耦、保险/限流、反接保护足够。
- [ ] 确认停止应“滑行”还是“制动”。默认 IN1=IN2=0、PWM=0；制动前先查驱动真值表。
- [ ] 轮子悬空时分别给很小正指令，若轮向错误只改对应 `MOTOR_*_COMMAND_SIGN`，不要互换多处逻辑。

## AB 编码器

- [ ] 编码器输出电平、输出类型（推挽/开漏）、每相供电及是否需要外部上拉；STM32 引脚不得超过容限。
- [ ] 左 A/B 接 PA0/PA1（TIM2 CH1/CH2），右 A/B 接 PA6/PA7（TIM3 CH1/CH2）。
- [ ] 当前 TIM Encoder Mode TI12 通常得到四倍频计数；必须手转车轮一整圈记录实际 tick。
- [ ] 正向转轮时累计 tick 应为正；若为负只改对应 `*_ENCODER_SIGN`。
- [ ] 根据轮径、减速比、实测每圈 tick 重新计算 `DISTANCE_PER_TICK_M`。
- [ ] `ENCODER_INPUT_FILTER=6` 和内部上拉只是首版值；长线、开漏或强干扰现场应按示波器结果调整。
- [ ] 当前单周期异常阈值 1000 tick/10 ms、堵转 1 s 是保守占位值，要按最高转速和机械惯量复核。

## 机械与控制

- [ ] 当前尺量轮心间距为 330 mm；仍需原地多圈旋转标定运动学有效轮距，并标定负载后的左右有效轮周。
- [ ] 先验证开环小占空比与编码器符号，再闭环；不要一开始就给满速。
- [ ] PID 0.625/0.125/0 来自旧 ESP32 且误差单位为 mm/s，只是迁移起点，不是新底盘的最终整定值。
- [ ] 实测最大安全线速度/角速度/轮速，更新三个限幅宏。
- [ ] 抬轮测试 STOP、拔 UART、停止发送 CMD_VEL、堵住单侧编码器，确认均按文档停机并上报 fault_flags。

## EMI 与整机安全

- [ ] 电机端抑制、电源回路、地线拓扑不会让 MCU 复位或 UART/编码器误码。
- [ ] 看门狗、急停、电源继电器等系统级安全要求由整机风险评估决定；当前软件超时不能替代硬件急停。
- [ ] 足浴环境涉及水、电、人体接触：电机/主电源隔离、防水、防漏电与认证应由合格硬件/安规人员审核。
